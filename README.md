## 👨‍💻 O mnie

Mam 19 lat i jestem full stack developerem. Tworzę aplikacje webowe i desktopowe — od interfejsu użytkownika po backend. Najbardziej interesują mnie projekty związane z mapami oraz narzędziami ułatwiającymi pracę użytkownikom.

## 🚀 Projekty

**[MapCreator](https://github.com/TimiDev-be/MapCreator)**

Edytor map umożliwiający rysowanie linii, wielokątów i markerów oraz eksportowanie map do PDF z wykorzystaniem własnych szablonów HTML.

Aktualnie przepisuję projekt od podstaw, wykorzystując Electron.
